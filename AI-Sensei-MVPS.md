# MVPs for AI teacher

## MVP 1

### Admin Panel

#### Course Management

- Create, edit, delete courses
- Create and order weeks within a course
- Add the following content for each week:
  - Weekly intro image
  - Target phrase
  - Basic english content
  - Activity time content
  - Story Time Content
- Add vimeo links to content
  - Chapter timestamps
- Add lesson titles and guides
- Upload activity materials where applicable
- Preview content before publishing

### Teacher UI

#### Course Access

- Login
- Show the Course assigned to the teacher's Organisation
- Automatically show the current week based on the Organisation's plan
- Allow nav to previous/next weeks

#### Week view

- Show the weekly intro image
- Show target phrases (maybe incorporated into image?)
- Show the three lesson types in order
  - Basic English
  - Activity Time
  - Story Time
- **ASK ABOUT** Extra story time selector? Possibly as a filler until we finish content

#### Lesson View

- Show the weekly background as an overlay, with video link/content buttons neatly listed in a commonly defined menu area for clear ease of access.

#### Video Player

- When a teacher clicks a 'start video' link from the lesson menu it should load the player full screen on the TV straight from mirroring mode.
- The video should have an overlay "remote control" for the player, with the guide appearing on screen during this time also.

##### Remote

- Play/pause
- Skip forward/back 5s
- Change playback speed
- Large tablet-friendly controls
- Chapter skip forward/back

#### Materials

- View PDF materials
